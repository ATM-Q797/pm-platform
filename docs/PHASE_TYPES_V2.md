- 主位映射：`P1..P9`（P8 联调测试、P9 交付为独立主位）

- 旧值兼容：`P6`（旧样机打样）排序键 = `(6, 0)`（P71 之前）；**旧 `P7`（联调测试）→ `(8, 0)`、旧 `P8`（交付）→ `(9, 0)`**（语义跟随新编号，评审处置：避免旧联调测试排在 P71/P72 之前）；未知类型排最后（现有行为）
