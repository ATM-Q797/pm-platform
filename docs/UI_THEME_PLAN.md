## 一、登录页（参考 DeepSeek 首页）

### 1.1 DeepSeek 首页设计特征（已抓取分析）

| 特征 | 表现 |
|------|------|
| 极简导航 | 顶部仅 logo + 少量文字链接，大量留白 |
| 中央大标题 | 超大字号 slogan（"探索未至之境"），粗字重 |
| 副标题 | 标题下一行小字说明 |
| CTA | 大圆角按钮（"开始对话"），视觉焦点唯一 |
| 留白 | 页面上下左右大量留白，无杂乱卡片 |
| 背景 | 浅色为主，柔和渐变，几乎无边框元素 |

### 1.2 我们的登录页映射

```

│                                             │

│          │  [登 录]（大圆角主按钮）│          │  ← 登录卡片（16px 圆角、无边框、
```

- 全屏居中 + 大留白（DeepSeek 的呼吸感）
- 中央大标题/副标题 + 唯一焦点（登录卡片）
- 登录卡片：`borderRadius: 16`、无边框、柔和阴影、半透明白底（深色模式下半透明深底）
- 背景：浅色 = 柔和白→浅蓝灰渐变；深色 = 深蓝灰渐变（与主题联动，登录页也支持深浅）
- 大按钮：圆角 10+、主色渐变 hover

## 二、深色 / 浅色模式

### 2.1 架构

```
用户点击右上角开关（Sun/Moon）
        │
        ▼
ThemeContext（App 顶层）
  state: 'light' | 'dark'
  ├─ localStorage 持久化（theme 键）
  ├─ <html data-theme="dark">（自定义 CSS 生效开关）
  └─ ConfigProvider theme.algorithm = darkAlgorithm | defaultAlgorithm
                                    （AntD 组件自动切换）
```

**初始化防闪白（FOUC）**：`index.html` 内联小脚本，页面渲染前读 localStorage 设置 `<html data-theme>`——刷新/首访不闪白。

**默认值**：首次访问跟随系统偏好（`prefers-color-scheme`），之后记住用户选择。

### 2.2 右上角开关（用户区旁）

```
[🌙/☀️ 主题按钮] [👤 用户名 · 角色 ▾]
```
- 图标按钮（MoonOutlined / SunOutlined），点击即时切换，无刷新
- 位置：Header 最右侧，用户 Avatar 左侧（用户要求）

### 2.3 需要适配的样式层（工作量重点）

| 层 | 处理方式 |
|----|----------|
| **AntD 组件** | 自动（ConfigProvider darkAlgorithm 切换 token）✅ 零成本 |
| **index.css**（卡片阴影/周报样式/hover） | 改为 **CSS 变量**：`:root` 定义浅色变量，`[data-theme="dark"]` 覆盖 |
| **gantt.css（甘特图，最重）** | 全文件改 CSS 变量：状态色/网格线/表头/今日线/滚动条——深色下 dhtmlx 默认白底会刺眼，需完整 dark 覆盖 |
| **resourceView.css** | 同上变量化 |
| **各页面内联 style 硬编码色**（DashboardPage CARD_STYLE、状态色 map、LoginPage 渐变等） | 两方案：① 改 CSS 变量引用（推荐，style 里用 `var(--xxx)`）；② 通过 useTheme 取 token 动态算 |
| **Header** | 深色下 Header 保持深蓝（#001529）可不变，或跟随主题浅色时改白底深字——建议**浅色时 Header 也变浅**（更现代），深色时保持深色 |

### 2.4 深色模式色板（初始定义）

```
背景层：  layout #0f1115 ／ 容器 #16181d ／ 浮层 #1e2128
文本：    主 #e6e6e6 ／ 次 #9ca3af ／ 禁用 #4b5563
边框：    #2a2d34
语义色：  保持 AntD dark 默认（蓝 #1677ff、红 #ff4d4f、金 #faad14、绿 #52c41a）
甘特条：  状态色提亮一档（dark 下 #69b1ff/#73d13d 等更醒目）
```
