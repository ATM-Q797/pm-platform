**机制设计**：
- 表 `data_change_events`：id / project_id / phase_id / field / old_value / new_value / source / changed_by / changed_by_name / project_name / phase_name / reason / created_at。

- 服务函数签名：`record_change_event(db, *, user, project_id, phase_id, field, old, new, source, reason=None)`；字段中文映射 FIELD_LABELS
- 端点权限：登录即可查（`get_current_user`），按 project_id/phase_id/field/source 过滤，limit 默认 50 max 200，按 created_at 倒序
