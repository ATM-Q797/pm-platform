本批任务：Phase 8 8-1 数据看板增强，含 5 个功能点（P0 环比标记 + P0 今日风险队列 + P1 口径内嵌 + P2 盘面导出 + P1 空态与数据日期）。

设计要点：

**① 环比标记（P0）**
- 后端：`snapshot.py` 的 `_WEEKLY_DELTA_KEYS` 新增 `delayed_phases` / `conflict_pairs` 两个周差分键；`build_trend` 返回结构增加这两个差分值。
- 前端：看板 4 张卡（总数/延期/即将到期/冲突）各显示「较上周 +N / −N」小字；延期类上升为红、下降为绿；总数类上升为蓝、下降为灰。
- 口径：差分 = 本周最新快照值 − 上周同日快照值（周一锚点，与 `build_trend` 周聚合同源）。

**② 今日风险队列（P0）**
- 后端：`dashboard.py` 新增 `build_risk_queue(db)` 函数，合并三来源：
  - 延期阶段（`delayed_phases`，severity=3）
  - 即将到期（`due_soon_phases`，severity=2）
  - 资源冲突（`resource_conflicts.detect_conflicts`，severity=2）
  - 按 severity 降序、同级按 overdue_days/days_left/overlap_days 降序。
  - 输出：`[{project_id, project_name, phase_name, type: 'overdue'|'due_soon'|'conflict', severity, detail, days}]`
- 前端：看板新增「今日风险」卡（默认展开前 10 条，点行跳项目详情），条数显示总数。

**③ 口径内嵌说明（P1）**
- 前端：看板每张卡的指标名旁加 `Tooltip`，写明计算口径（静态文案，与 `PHASE8_PLAN.md §一` 各指标口径一致）。
- 文案示例：「延期 = 阶段 plan_end < 今天 且状态 ∉ {已完成, 搁置}，排除专项」。

**④ 盘面导出（P2）**
- 前端：看板工具栏加「导出」按钮，调用已有的 `html2canvas`（AnalysisModal 已在用）截图为 PNG；指标导出复用 `exports.py` 的 Excel 生成逻辑。
- 不引新依赖。

**⑤ 空态与数据日期（P1）**
- 前端：看板顶部标注「数据截至 <快照日期>」；无快照时显示空态提示「暂无快照数据，请在分析弹窗中触发采集」+ 触发按钮（调 `POST /api/analysis/snapshots/run`）。
