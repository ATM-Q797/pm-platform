一、口径定义（列名锚定真表）：

1. 计划稳定性（项目粒度）
   - 数据源：data_change_events，field ∈ {plan_start, plan_end, phase_plan_start, phase_plan_end}（白名单计划字段，change_events.py FIELD_LABELS 守门）。
   - 计划改动次数 = 窗口内事件条数（项目级/阶段级分列 + 合计）。
   - 累计挪动天数 = Σ|new−old|（逐事件按日期差取绝对值，分列 + 合计）。
   - 计数语义：按字段变更事件计次计天——一次编辑同改两字段 = 2 次、整体平移按字段各计；口径 Tooltip 注明「按字段变更事件计」。
   - 值解析：old_value/new_value 按 YYYY-MM-DD 解析；解析失败计入 move_parse_skipped 显式返回，不静默丢弃、不计天数。
   - 分支出处（可复现）：日期首次设置/清空事件的 old_value 或 new_value 为空、非日期字面 → 解析失败入 skipped。
   - 窗口过滤：created_at ∈ 窗口。

2. 估算偏差（阶段粒度，项目/市场聚合）
   - 首次计划工期 = first_plan_end − first_plan_start。
   - 首次计划取值（配对规则：按字段独立取首值再成对）：每字段首值 = 该字段有事件 → 其最早事件 old_value；无事件 → phase 对应列现值（未改过即首次）；old_value 为空（日期首次设置无旧值）→ 首值缺失。
   - 两字段首值成对可用才计入；否则归 first_plan_skipped，该阶段不计入并显式计数。
   - 分支出处：old_value 空值场景可复现——阶段 plan_end 为空时首次设置 → 事件 old_value 空串 → 无首值；成对缺失有在案观察——依据 docs/PHASE8_PLAN.md「N 个活跃阶段无计划日期，未纳入判定」。
   - 实际工期 = actual_end − actual_start（phase 表真列）。
   - 偏差天数 = 实际工期 − 首次计划工期；交付偏差 = actual_end − first_plan_end（并列展示）。
   - 仅统计 actual_end 非空阶段；在途不计（口径不可比）。
   - 窗口过滤：actual_end ∈ 窗口。
   - 受边界「历史不回填」约束：首次计划的回溯深度以 P1 上线日为界，页面常驻数据起点注。

3. 审批时效（全局/市场粒度）
   - 数据源：phase_change_request（提交时刻 = created_at、决于 = reviewed_at——列名已核 models/audit.py）。
   - 时效 = reviewed_at − created_at；统计口径 = 窗口内已决行（status ∈ approved/rejected）均值（小时）+ 件数；pending 不计。
   - 口径细化注明：「批下来」按「决于」读（含驳回件），仅 approved 均值可切换。
   - source=approval 事件只作条数对照，不参与时效计算（事件表无提交时刻）。
   - 窗口过滤：reviewed_at ∈ 窗口。
