# Phase 3 实施计划：前端甘特图平台

## 决策汇总（已确认）
1. **一次性做完整 Phase 3**：列表 + 甘特图 + 拖拽改期 + 阶段编辑面板 + 返工标记
2. **支持拖拽改期+保存**：社区版 `onAfterTaskDrag` 事件 → 调 `PUT /api/phases/{id}`
3. **默认项目列表页**：`/` → 项目列表，点击进入 `/projects/:id` 甘特图

## 技术调研结论
- **dhtmlx-gantt 社区版现已是 MIT 协议**（非规格书 §2.4 说的 GPL），无开源传染顾虑
- 社区版**支持**：FS/SS/FF/SF 全依赖类型、拖拽改期、拖拽改工期、改进度、中文 locale
- 社区版**不支持**：auto_scheduling 自动联动（Pro 功能）。→ 拖拽只改被拖阶段本身，后续不自动推后（与后端 API 行为一致）
- 拖拽存盘方案：`gantt.attachEvent("onAfterTaskDrag", ...)` 释放后调 API

## 第 1 步：前端项目骨架

用 Vite 初始化 React + TypeScript，安装依赖：
```
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install antd axios dayjs dhtmlx-gantt
npm install -D @types/dhtmlx-gantt
```

目录结构（按规格书 §1.4）：

## 第 2 步：API 封装层 + 类型定义
- `types/index.ts`：Project / Phase / Dependency / GanttData / Resource 等类型，与后端 schema 一一对应
- `api/client.ts`：axios 实例，`baseURL: 'http://localhost:8000/api'`（开发期直连后端）
- `api/*.ts`：每个实体的请求函数（getList / get / create / update / delete / getGantt / rework）

## 第 3 步：项目列表页（默认页 `/`）
- antd Table：项目编号 / 名称 / 类目 / 市场 / 状态 / 负责人 / 计划周期 / 操作
- 顶部筛选：状态（多选）、市场、类目
- 状态用 antd Tag 着色（进行中蓝、已完成绿、未开始灰、已搁置深灰）
- 点击行 → 跳转 `/projects/:id`
- 右上角"导入 Excel"按钮（调 POST /api/import/excel，显示导入报告 Modal）

## 第 4 步：甘特图组件（核心）
`components/Gantt/GanttChart.tsx` 封装 dhtmlxGantt：
- `useRef` 拿容器 div，`useEffect` 初始化 `gantt.init()`
- `ganttConfig.ts` 配置：
  - 时间轴 scale：日/周/月切换
  - 左侧列：阶段名（tree）、负责人、开始、工期
  - task_class：按状态着色（已完成绿/进行中蓝/未开始灰/延期红/已搁置深灰）
  - 返工标记：rework_count>0 加橙色左边框（自定义 CSS）
  - 中文 locale
  - markers：今天标记线
- 数据源：`GET /api/projects/:id/gantt` → `gantt.parse()`
- **拖拽改期存盘**：`onAfterTaskDrag` 事件 → 取 task 的 start_date/duration → 算 plan_start/plan_end → `PUT /api/phases/:id`
- 拖拽改工期同理（resize）
- 拖拽改进度（progress）同理
- **依赖连线**：从 gantt 数据的 links 渲染（社区版支持显示 + 拖拽新建连线 → POST /api/dependencies）

## 第 5 步：项目详情页 `/projects/:id`
- 顶部：项目基本信息卡片（可编辑 → PUT /api/projects/:id）
- 主体：GanttChart 组件（占满下方）
- 时间轴工具栏：日/周/月切换、展开/折叠所有、回到今天
- 点击甘特条 → 弹出 PhaseEditor

## 第 6 步：阶段编辑面板 `PhaseEditor.tsx`
- antd Drawer 抽屉（从右侧滑出）
- 表单字段：阶段名、phase_type、状态（Select）、进度（Slider 0-100）、计划开始/结束、实际开始/结束、负责人（多选 Resource）、交接人、备注、返工次数（只读）
- 底部操作：保存（PUT）、返工（POST /rework，弹窗填原因）、删除（DELETE）
- 保存后刷新甘特图

## 第 7 步：返工标记显示
- 甘特条 CSS：`.task_rework { border-left: 4px solid #fa8c16; }`
- 通过 `gantt.templates.task_class` 给 rework_count>0 的任务加 class
- PhaseEditor 里显示返工次数 + 返工按钮

## 关键技术风险与对策
| 风险 | 对策 |
|---|---|
| dhtmlxGantt 与 antd 样式冲突 | gantt 容器加 scoped class，CSS 隔离 |
| 拖拽存盘日期格式不匹配 | 后端用 ISO date，前端转换时统一 YYYY-MM-DD |
| 社区版无 auto_scheduling | 明确告知用户：拖拽只改单阶段，不自动联动（与后端一致） |
| gantt 实例单例导致多页面复用问题 | 组件卸载时 gantt.clearAll() + 解绑事件 |
